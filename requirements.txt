# The pipeline's own dependencies. Airflow is deliberately NOT here.
#
# Airflow and dbt pin conflicting versions of jinja2, pydantic and requests, so
# installing them together breaks one or the other. Airflow lives in a separate
# virtualenv and invokes this project as a subprocess rather than importing it,
# which is why dags/ imports a package this file does not install. See the
# Deployment section of README.md.
#
#   python3 -m venv ~/pipeline-venv && ~/pipeline-venv/bin/pip install -r requirements.txt
#   python3 -m venv ~/airflow-venv  && ~/airflow-venv/bin/pip install "apache-airflow==3.3.1" \
#       --constraint "https://raw.githubusercontent.com/apache/airflow/constraints-3.3.1/constraints-3.12.txt"
